# ذاكر بذكاء · Study Smart

أداة ويب تساعد الطالب يذاكر سلايدات محاضرته بذكاء — يرفع ملف PDF، والنظام يحلّله ويشرح له كل سلايد بالاعتماد على **Claude API**.

أداة تعمل بالكامل في المتصفح (HTML / CSS / JavaScript فقط) بدون أي خادم خلفي.

---

## المميزات

- **رفع السلايدات (PDF):** سحب وإفلات أو اختيار ملف.
- **ملخّص الملف:** عدد الصفحات، عنوان الملف، والمواضيع الرئيسية، مع ملخّص عام — يولّده Claude.
- **اختيار السلايدات:** معاينة مصغّرة لكل صفحة، تختار اللي تبي تذاكره.
- **شرح لكل سلايد:** الشرح على اليسار، السلايد في الوسط، والتنقّل بين السلايدات على اليمين.
- **اسأل عن السلايد:** محادثة عن السلايد الحالية.
- **كويز:** أسئلة اختيار من متعدد للسلايدات المختارة مع التصحيح والتوضيح.
- **نقاش الشابتر:** محادثة عن محتوى الملف كامل.

---

## التشغيل

1. افتح `index.html` في المتصفح مباشرة.
   - أو شغّل خادمًا محليًا بسيطًا (أفضل):
     ```bash
     python3 -m http.server 8000
     # ثم افتح: http://localhost:8000
     ```
2. روح لصفحة **الإعدادات** (`#/settings`).
3. حط **مفتاح Claude API** (تحصل عليه من `console.anthropic.com`) واضغط **حفظ**.
   - تقدر تضغط **اختبار الاتصال** للتأكد أن المفتاح يعمل.
4. ارجع للرئيسية وارفع ملف الـ PDF، وابدأ المذاكرة.

> يحتاج اتصال بالإنترنت: لتحميل مكتبة قراءة PDF (PDF.js من CDN) وللاتصال بـ Claude.

---

## أين يُحفظ مفتاح Claude؟

لأسباب **أمنية**، المفتاح يُخزَّن محليًا في متصفحك فقط عبر `localStorage`، ولا يُكتَب في كود المشروع ولا يُرفع إلى GitHub.
بهذا الشكل يبقى محفوظًا على جهازك ويستخدمه النظام تلقائيًا في كل العمليات — لكنه لا يتسرّب لأي شخص آخر.

- لمسح المفتاح: افرغ الحقل في الإعدادات واحفظ، أو امسح بيانات الموقع من المتصفح.
- المفتاح يبقى محفوظًا على نفس الجهاز/المتصفح بين الجلسات.

### الموديل
الافتراضي `claude-opus-5-5` (الأذكى). تقدر تختار من الإعدادات موديلًا أوفر مثل `claude-sonnet-5-5` أو `claude-haiku-5-5` إذا سلايداتك كثيرة.

## البنية

```
study-smart/
├── index.html          # الواجهة والعروض (رفع / ملخص / مذاكرة / إعدادات)
├── css/styles.css      # التنسيق (RTL، واجهة عربية)
└── js/
    ├── claude-api.js   # غلاف Claude Messages API (مع البث JSON) + تخزين الإعدادات
    ├── pdf-handler.js  # قراءة PDF واستخراج النص ورسم الصفحات (PDF.js)
    └── app.js          # منطق التطبيق والتوجيه والحالة
```

## ملاحظات تقنية

- الاتصال بـ Claude يتم مباشرة من المتصفح باستخدام ترويسة
  `anthropic-dangerous-direct-browser-access: true` (CORS).
- استخراج نص السلايدات يعتمد على كونها نصّية (قابلة للنسخ). السلايدات الصُّورية (ممسوحة ضوئيًا) قد لا يُستخرج منها نص.
